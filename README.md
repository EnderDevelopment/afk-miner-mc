# AFK Miner

AFK Miner is a Minecraft plugin designed to automate mining tasks while you are away from your keyboard. It provides a graphical user interface (GUI) to configure mining parameters such as the number of blocks to mine and the direction of mining. The plugin also allows you to specify which inventory slots to keep items in, ensuring you always retain at least one item from those slots. This plugin is compatible with Minecraft version 1.8.8.

## Install

1. Download the AFK Miner plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your Minecraft server to load the plugin.

## Use

1. Join your Minecraft server.
2. Type `/afkminer` in the chat to open the AFK Miner GUI.
3. Configure the mining parameters:
   - Set the number of blocks to mine.
   - Specify the direction of mining (forward, backward, left, right).
   - Select the inventory slots to keep items in.
4. Start the AFK mining process.
